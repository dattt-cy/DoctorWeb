# DoctorFrontend

Frontend Next.js cho website công khai và trang quản trị phòng khám.

## Các thư mục chính

- `src/app`: route và layout của Next.js.
- `src/features`: API, type và UI gắn với từng nghiệp vụ.
- `src/shared`: HTTP client và thành phần dùng chung, không phụ thuộc feature.
- `src/components`: layout và section dùng để ghép trang.
- `src/constants`: nội dung tĩnh của website.

## Lệnh

```powershell
npm install
npm run dev
npm run lint
npm run build:next
```

Xem hướng dẫn môi trường và backend trong README ở thư mục gốc.
